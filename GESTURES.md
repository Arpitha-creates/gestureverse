# GestureVerse — Gesture Card

A one-page reference. Print it, or keep it open on a second screen.
The same guide is available in-app via the **Guide** button or the **G** key.

---

## The core interaction

```
   DRAW IT             PINCH IT            LIFT IT             MOVE IT            RELEASE
   index finger   →    thumb + index  →    (depth)       →     carry         →    leave it
```

---

## Gestures

| # | Gesture | What it does |
|---|---|---|
| 1 | **Index finger up**, other fingers folded | The cursor follows your fingertip |
| 2 | Point, in **Draw** mode | Draw a stroke |
| 3 | **Open your hand** | Finish the stroke |
| 4 | **Thumb + index pinch** | Grab the drawing under the cursor |
| 5 | Pinch held, hand moves | Carry the drawing, including in depth |
| 6 | **Release the pinch** | Leave it floating where it is |
| 7 | **Pinch with both hands** | Grab with two hands |
| 8 | **Hands apart / together** | Resize the drawing |
| 9 | **Twist both hands** | Rotate the drawing |
| 10 | **Fist held over a drawing** | Delete it, after a 0.9 s red charge ring |
| 11 | Hold with one hand, **fist the other** | Delete the held drawing |
| 12 | **Open palm held 1.5 s** | Undo the last action |

---

## Keys

| Key | Action |
|---|---|
| `U` | Undo |
| `R` | Redo |
| `C` | Clear the canvas |
| `E` | Toggle eraser |
| `G` | Gesture guide |
| `Esc` | Release everything immediately |
| `1` / `2` | Draw / Play mode |

---

## Tips

- **Draw mode** draws when you point. **Play mode** only selects, so use it when you want
  to arrange things without adding ink.
- Keep your whole hand in frame — tracking degrades at the edges.
- A pinch needs your index tip held out in front of your palm. Folding everything into a
  fist is read as a fist, not a pinch.
- Good lighting in front of you beats a better camera.
