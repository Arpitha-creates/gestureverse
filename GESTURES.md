# GestureVerse — Gesture Card

A one-page reference. Print it, or keep it open on a second screen at the booth.
The same guide is available in-app via the **Gesture guide** button or the **G** key.

---

## The core interaction

```
   DRAW IT              TURN IT INTO          GRAB IT            MOVE IT            RELEASE
   in the air    →      an object      →      (pinch)      →     (carry)      →     (let go)
```

---

## Gestures

| # | Gesture | What it does |
|---|---|---|
| 1 | **Index finger up**, other fingers curled | Move the cursor. A glowing dot tracks your fingertip. |
| 2 | Point while in **Air Drawing** | Draw a stroke. It appears as you move. |
| 3 | **Thumb + index pinched** | Grab the object under the cursor. It attaches to your hand. |
| 4 | Pinch held, **hand moves** | Lift and carry the object. It follows smoothly. |
| 5 | **Release the pinch** | Place it. Or, if you were moving fast, throw it. |
| 6 | **Two hands apart / together** | Scale the held object up and down. |
| 7 | **Two hands twisting** | Rotate the held object. |
| 8 | **Open palm** | End the current stroke. **Hold it for about a second** to pause. |
| 9 | **Closed fist** | Erase whatever the cursor is over. |
| 10 | **Fast flick, then release** | Throw the object. It flies, bounces and settles. |

---

## Things that are deliberately NOT gestures

- **A fist never clears the scene.** It erases only the single object under your cursor. There is no
  gesture in GestureVerse that wipes everything — clearing the canvas is a button.
- **An open palm never draws or grabs.** It pauses.
- **Half-open, ambiguous hands do nothing.** The app waits for a clear pose rather than guessing.

## Getting the tracking right

| Do | Don't |
|---|---|
| Keep your whole hand in frame | Let your fingers drift off the edge |
| Hold your hand an arm's length away | Put your hand right against the lens |
| Face your palm towards the camera | Track with the back of your hand |
| Use decent, even lighting | Sit with a bright window behind you |
| Move at a normal speed | Wave frantically |

**If the cursor is shaky:** lower the Sensitivity slider, or choose the **Relaxed** preset.
**If the cursor feels laggy:** raise it, or choose **Responsive**.

## Keyboard shortcuts

| Key | Action |
|---|---|
| `Space` | Turn the last stroke into an object |
| `G` | Toggle the gesture guide |
| `H` | Hide / show the side panels (clean demo mode) |
| `Esc` | Clear the canvas |

---

## On-screen controls

- **Modes** — Air Drawing · Object Playground · Creative Playground
- **Colour** — eight neon swatches
- **Brush** — four sizes
- **Tool** — freehand, line, rectangle, square, circle, ellipse, triangle, star
- **Create** — turn the current stroke into an object, using the shape dropdown
- **Undo / Redo / Clear canvas / Save snapshot / Reset all**
- **Sensitivity** — slider plus Relaxed / Balanced / Responsive presets
- **Options** — camera preview, allow throwing, primary hand
